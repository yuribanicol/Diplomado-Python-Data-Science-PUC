# Python & Data Science Diploma Portfolio (PUC) 🐍📊

This repository compiles 12 practical miniprojects developed during the **Postgraduate Diploma in Python and Data Science** at **Pontificia Universidad Católica de Chile (2026)**. The portfolio demonstrates a structured progression from core programming fundamentals and Object-Oriented Programming (OOP) to database engineering (SQL/NoSQL) and Machine Learning evaluation.

---

## 📂 Repository Structure & Modules

### 1. Python Programming Fundamentals
Core algorithmic logic, control flow, data structures, and external file parsing.
* **Miniproyecto 1:** Interactive CLI number-guessing game implementing `random`, `while` loops, and distance-based conditional feedback.
* **Miniproyecto 2:** Multi-round e-commerce budget and pricing simulator with dynamic string manipulation and conditional cost rules.
* **Miniproyecto 3:** Clinical exam and patient queue management system reading external `.txt` and `.csv` records into dictionaries.

### 2. Software Development with Python (OOP)
Modular architecture, custom data structures, inheritance, and state-driven simulations.
* **Miniproyecto 1:** Movie database query engine parsing `.csv` datasets into tuples/lists to filter, sort, and compute statistical metrics.
* **Miniproyecto 2:** Vehicle physics and component wear simulation (`Automóvil` & `Moto` classes) modeling acceleration, braking, and tire resistance degradation.
* **Miniproyecto 3:** Multi-class restaurant operations simulator (`Cocinero`, `Repartidor`, `Cliente`, `Restaurante`) modeling energy depletion, order fulfillment, and service quality scoring.

### 3. Python & Databases (SQL & NoSQL)
Database schema design, ETL ingestion scripts, complex relational queries, and REST API integration.
* **Miniproyecto 1:** MySQL database connection (`mysql-connector-python`), filtered `SELECT` queries, and parameterized record insertion.
* **Miniproyecto 2:** Relational e-commerce database (`mp2`) automating table creation with Primary/Foreign Keys (`carga.py`), CSV bulk loading, and multi-table `JOIN` analytical queries (`consultas.py`).
* **Miniproyecto 3:** Automated REST API data extraction (`requests`) stored into a MongoDB NoSQL collection (`pymongo`), featuring date-range, regex, and boolean queries.

### 4. Data Mining & Machine Learning
Analytical case studies covering data preprocessing, dimensionality reduction, supervised classification, and business-aligned model evaluation.
* **Miniproyecto 1:** ETL pipeline evaluation (handling outliers via trimmed means and preserving categorical features) and dimensionality reduction comparison (**PCA vs. t-SNE**).
* **Miniproyecto 2:** Supervised classification analysis comparing **Random Forest**, **Decision Trees**, and **K-Nearest Neighbors (KNN)** (Euclidean/Hamming distance metrics) alongside bias-variance/overfitting diagnostics.
* **Miniproyecto 3:** Critical ML pipeline audit addressing data leakage, stratified Hold-out vs. K-Fold Cross-Validation, confusion matrix calculations, and **Recall-driven model selection** for customer churn prevention.
